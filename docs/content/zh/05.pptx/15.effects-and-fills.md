## 图片填充（Blip Fill）

`data` 字段接受原始字节（`Uint8Array`、`ArrayBuffer`、`Buffer`），也支持 base64 [data URL](https://developer.mozilla.org/en-US/docs/Web/HTTP/Basics_of_HTTP/Data_URIs)（如 `data:image/png;base64,...`）。

```ts
import * as fs from "node:fs";
```

::api-example{type="pptx"}

```json [JSON]
{
  "slides": [
    {
      "children": [
        {
          "shape": {
            "x": "1.3cm",
            "y": "1.3cm",
            "width": "15.9cm",
            "height": "9.3cm",
            "properties": {
              "fill": {
                "type": "blip",
                "data": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAQAAAC1HAwCAAAAC0lEQVR42mNkYAAAAAYAAjCB0C8AAAAASUVORK5CYII=",
                "imageType": "png"
              }
            }
          }
        }
      ]
    }
  ]
}
```

```ts [TypeScript]
{
  children: [
    {
      shape: {
        x: "1.3cm",
        y: "1.3cm",
        width: "15.9cm",
        height: "9.3cm",
        properties: {
          fill: {
            type: "blip",
            data: new Uint8Array(fs.readFileSync("texture.png")),
            imageType: "png",
          },
        },
      },
    },
  ],
}
```

### 3D 旋转和斜面

3D 拆成两个形状属性 —— **不在** `effects` 下：

- `scene3d`（`a:scene3d`）—— 3D 场景：`camera` 与 `lightRig`（可选
  `backdrop`）。相机旋转是球坐标 `{ lat, lon, rev }`，单位为度；`lightRig`
  携带 `rig` 与 `direction`。
- `shape3d`（`a:sp3d`）—— 3D 形状本体：`bevelT`/`bevelB`（顶/底斜面）、
  `extrusionH`、`contourW`、`z` 与 `prstMaterial`。

## Effects 选项

`effects` 只承载扁平的 2D 效果（`EffectListOptions`）。3D 直接位于形状上，分属
`scene3d` 与 `shape3d`。

| 属性                  | 类型                              | 说明                                                                             |
| --------------------- | --------------------------------- | -------------------------------------------------------------------------------- |
| `effects.blur`        | `BlurEffectOptions`               | 模糊效果                                                                         |
| `effects.glow`        | `GlowEffectOptions`               | 发光效果（`radius` + `color`）                                                   |
| `effects.innerShadow` | `InnerShadowEffectOptions`        | 内部阴影（`blurRadius`、`distance`、`direction` 单位为度、`color`）              |
| `effects.outerShadow` | `OuterShadowEffectOptions`        | 外部阴影（`blurRadius`、`distance`、`direction` 单位为度、`color`）              |
| `effects.reflection`  | `ReflectionEffectOptions \| true` | 倒影（`blurRadius`、`distance`、`direction` 单位为度、`startAlpha`、`endAlpha`） |
| `effects.softEdge`    | `number \| UniversalMeasure`      | 柔化边缘半径 —— 标量（EMU 或 UniversalMeasure）                                  |
| `scene3d`             | `Scene3DOptions`                  | 3D 场景 —— `camera` 与 `lightRig`（角度单位为度）                                |
| `shape3d`             | `Shape3DOptions`                  | 3D 形状本体 —— `bevelT`/`bevelB`、`extrusionH`、`contourW`、`z`、`prstMaterial`  |

阴影与发光的 `color` 是 `SolidFillOptions`（`{ value, transforms }`）；不透明度
通过 `color.transforms.alpha`（整数百分比）传入，而非顶层 `alpha`。
