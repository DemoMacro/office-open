形状是幻灯片的主要构建块。一个形状可以通过 `textBody` 属性来包含文本内容。

## 基本形状

```ts
import { generatePresentation } from "@office-open/pptx";
```

::api-example{type="pptx"}

```json [JSON]
{
  "slides": [
    {
      "children": [
        {
          "shape": {
            "x": "1.3cm",
            "y": "1.3cm",
            "width": "13.2cm",
            "height": "7.9cm",
            "textBody": { "text": "Simple text" }
          }
        }
      ]
    }
  ]
}
```

```ts [TypeScript]
{
  children: [
    {
      shape: {
        x: "1.3cm",
        y: "1.3cm",
        width: "13.2cm",
        height: "7.9cm",
        textBody: { text: "Simple text" },
      },
    },
  ],
}
```

::

## 几何预设

使用 `geometry` 选项设置形状类型：

::api-example{type="pptx"}

```json [JSON]
{
  "slides": [
    {
      "children": [
        {
          "shape": {
            "x": "2.6cm",
            "y": "2.6cm",
            "width": "5.3cm",
            "height": "4.0cm",
            "geometry": "ellipse",
            "fill": "4472C4",
            "outline": { "color": "2E74B5", "width": 12700 },
            "textBody": { "text": "椭圆" }
          }
        },
        {
          "shape": {
            "x": "10.6cm",
            "y": "2.6cm",
            "width": "5.3cm",
            "height": "4.0cm",
            "geometry": "triangle",
            "fill": "ED7D31",
            "outline": { "color": "C5504B", "width": 12700 },
            "textBody": { "text": "三角形" }
          }
        }
      ]
    }
  ]
}
```

```ts [TypeScript]
[
  { shape: { geometry: "ellipse", fill: "4472C4", outline: { color: "2E74B5", width: 2 } } },
  { shape: { geometry: "triangle", fill: "ED7D31", outline: { color: "C5504B", width: 2 } } },
];
```

::

可用的几何类型：

| Geometry      | 形状         |
| ------------- | ------------ |
| `"rect"`      | 矩形（默认） |
| `"ellipse"`   | 椭圆/圆形    |
| `"roundRect"` | 圆角矩形     |
| `"triangle"`  | 三角形       |
| `"diamond"`   | 菱形         |
| `"star5"`     | 五角星       |
| `"hexagon"`   | 六边形       |
| `"chevron"`   | V 形箭头     |
| `"arrow"`     | 箭头         |

使用 `outline` 添加边框：`{ "color": "2E74B5", "width": 12700 }`。不要使用 `strokeColor` 或 `strokeWidth`，这些不是有效的属性。

## 段落和文本片段

使用 `textBody.paragraphs` 完全控制文本格式：

::api-example{type="pptx"}

```json [JSON]
{
  "slides": [
    {
      "children": [
        {
          "shape": {
            "x": "1.3cm",
            "y": "1.3cm",
            "width": "15.9cm",
            "height": "6.6cm",
            "textBody": {
              "paragraphs": [
                {
                  "children": [{ "text": "Bold title", "bold": true, "size": 28, "fill": "2E74B5" }]
                },
                {
                  "children": [
                    { "text": "Normal text with " },
                    { "text": "italic", "italic": true },
                    { "text": " and " },
                    { "text": "colored", "fill": "FF0000", "underline": "single" }
                  ]
                }
              ]
            }
          }
        }
      ]
    }
  ]
}
```

```ts [TypeScript]
{
  children: [
    {
      shape: {
        x: "1.3cm",
        y: "1.3cm",
        width: "15.9cm",
        height: "6.6cm",
        textBody: {
          paragraphs: [
            {
              children: [{ text: "Bold title", bold: true, size: 28, fill: "2E74B5" }],
            },
            {
              children: [
                "Normal text with ",
                { text: "italic", italic: true },
                " and ",
                { text: "colored", fill: "FF0000", underline: "single" },
              ],
            },
          ],
        },
      },
    },
  ],
}
```

## TextRun 格式选项

```json
{
  "text": "Formatted text",
  "size": 24,
  "bold": true,
  "italic": true,
  "underline": "single",
  "strike": "sngStrike",
  "fill": "4472C4",
  "font": "Calibri",
  "highlight": {
    "value": "FFFF00"
  },
  "kern": 12,
  "outline": true,
  "shadow": true,
  "hyperlink": {
    "url": "https://example.com"
  }
}
```

`outline` 与 `shadow` 接受 `true`（使用合理默认）或完整选项对象——完整字段见 [轮廓与效果](./effects-and-fills)。`hyperlink`（外部 `url` 或内部 `slide` 跳转）见 [链接](./links)。

## 对齐方式

```json
{
  "properties": {
    "alignment": "left"
  },
  "children": [
    {
      "text": "Aligned text"
    }
  ]
}
```

## 段落属性

除对齐外，段落 `properties` 还承载缩进、间距、方向、制表位和默认 run 格式（`a:defRPr`）：

```ts
{
  paragraph: {
    properties: {
      indentLevel: 1, // 大纲层级（a:pPr @lvl）
      indent: 457200, // 首行缩进，EMU（a:pPr @indent）
      marginIndent: 457200, // 左边距，EMU（@marL）
      marginRight: 457200, // 右边距，EMU（@marR）
      lineSpacingPercent: 150, // 单倍行距的 150%（a:lnSpc）
      spaceBefore: 457, // 段前间距，磅（a:spcBef）
      spaceAfter: 457, // 段后间距，磅（a:spcAft）
      rightToLeft: true, // 从右到左文字流向（@rtl）
      eastAsianLineBreak: true, // 东亚换行（@eaLnBrk）
      latinLineBreak: true, // 拉丁文换行（@latinLnBrk）
      tabStops: [{ position: 914400, alignment: "left" }], // @pos EMU，"left"|"center"|"right"|"decimal"
      fontAlignment: "base", // "auto" | "top" | "center" | "bottom" | "base"（@fontAlgn）
      defaultRunProperties: { size: 24, font: "Calibri" }, // a:defRPr — 默认 run 格式
    },
    children: [{ text: "段落文本" }],
  },
}
```

## 文本锚点（垂直对齐）

控制文本在形状内的垂直位置：

::api-example{type="pptx"}

```json [JSON]
{
  "slides": [
    {
      "children": [
        {
          "shape": {
            "x": "1.3cm",
            "y": "1.3cm",
            "width": "13.2cm",
            "height": "7.9cm",
            "textBody": {
              "anchor": "top",
              "text": "Top-aligned text"
            }
          }
        }
      ]
    }
  ]
}
```

```ts [TypeScript]
{
  children: [
    {
      shape: {
        x: "1.3cm",
        y: "1.3cm",
        width: "13.2cm",
        height: "7.9cm",
        textBody: {
          anchor: "top", // "top" | "center" | "bottom" | "justify" | "distribute"
          text: "Top-aligned text",
        },
      },
    },
  ],
}
```

## 文本自适应

::api-example{type="pptx"}

```json [JSON]
{
  "slides": [
    {
      "children": [
        {
          "shape": {
            "x": "1.3cm",
            "y": "1.3cm",
            "width": "10.6cm",
            "height": "5.3cm",
            "textBody": {
              "text": "This text will shrink to fit the shape",
              "autoFit": "normal"
            }
          }
        }
      ]
    }
  ]
}
```

```ts [TypeScript]
{
  children: [
    {
      shape: {
        x: "1.3cm",
        y: "1.3cm",
        width: "10.6cm",
        height: "5.3cm",
        textBody: {
          text: "This text will shrink to fit the shape",
          autoFit: "normal", // 自动缩小文本以适应形状
          // 或 autoFit: "shape" 自动调整形状大小
        },
      },
    },
  ],
}
```
