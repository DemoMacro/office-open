The umbrella package provides one detection and parsing entry while preserving the existing option families. There is no separate legacy edit model: parsed documents are projected into `DocumentOptions`, `WorkbookOptions`, or `PresentationOptions`.

## Format Matrix

| Formats                | Parse | Generate | Patch | Result model                                    |
| ---------------------- | ----- | -------- | ----- | ----------------------------------------------- |
| `.doc`, `.xls`, `.ppt` | ✅    | ❌       | ❌    | Existing document/workbook/presentation options |
| `.rtf`                 | ✅    | ❌       | ❌    | `DocumentOptions`                               |
| `.odt`, `.ods`, `.odp` | ✅    | ✅       | ❌    | Format-family options plus generic ODF nodes    |
| ODF chart/database     | ✅    | ✅       | ❌    | Low-level chart/database document codecs        |
| `.csv`, `.tsv`         | ✅    | ✅       | ❌    | `WorkbookOptions` conversion                    |

Legacy binary parsing is intentionally read-only. The shared option models remain the editing and persistence contract used by OOXML, the editor, and cross-format conversion.

ODF document packages depend downward through `ocf` and `odf-schema`; peer ODF document packages do not import one another, and only the umbrella package aggregates all codecs.

ODF has complete generic element coverage through extension nodes. Its specialized typed surface currently covers common text, spreadsheet, and presentation structures; unsupported elements remain addressable through `odfExtensions`.

## Unified Parsing

```ts
import { readFile } from "node:fs/promises";
import { parseOfficeDocument } from "office-open/parse";

const data = new Uint8Array(await readFile("input.doc"));
const parsed = await parseOfficeDocument(data);
```

The returned object contains the detected `type` and one of the three option families. String input is supported for RTF.

## ODF Generation and Extensions

```ts
import { generateOdt } from "office-open/odf";

const data = generateOdt({
  sections: [{ children: [{ paragraph: "Written as ODT" }] }],
});
```

ODF packages store an uncompressed leading `mimetype` and include the ODF 1.3 manifest required by conforming consumers.

For elements outside the specialized surface, use the `odf` package's generic node APIs.

## CSV and TSV

```ts
import { csvToWorkbook, tsvToWorkbook } from "office-open/convert";

const workbook = csvToWorkbook("name,score\nAda,99");
```

Delimited-text conversion follows RFC 4180, preserves quoted line breaks, and keeps parsed cell values as strings without type guessing.
